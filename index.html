// workflow

From setup
to findings in minutes.

01
Register & Add Assets

Create your account, then add the targets you own or have explicit written permission to test. Vulnora maintains strict RBAC so your assets and findings stay protected.

02
Configure Your Scan

Select which modules to run — Nuclei, ZAP, logic flaws, IDORForge, or a full scan. For authenticated testing, provide Cookies (JSON) or JWT tokens.

modules: nuclei, zap, logic_flaws, idorforge
03
Launch & Monitor

Hit Start and watch real-time progress via Celery-backed polling. The scanner dynamically creates test accounts for cross-user IDOR validation.

04
Manual Validation via Proxy

Use the built-in ZAP Proxy + Repeater for deep manual validation. Point your browser to localhost:8090, intercept traffic, and replay modified requests.

05
Export Professional Report

Download a PDF report with full PoCs, CVSS-style risk scores, evidence, and compliance framework citations (NIST CSF, ISO 27001, GDPR, PCI DSS, SOC 2).

// installation

Two ways to run.

Docker is recommended for most users. Native Kali setup for those who want full control.

# 1. Clone
git clone https://github.com/Steven5233/vulnora.git
cd vulnora
# 2. Configure environment
cp backend/.env.example backend/.env
# Edit .env and set SECRET_KEY
# Generate one: openssl rand -hex 32
# 3. Launch full stack
docker compose up --build -d
# Access points:
# Frontend → http://localhost:8501
# API → http://localhost:8000
# ZAP Proxy → http://localhost:8090
# Flower → http://localhost:5555
# 1. Install prerequisites
sudo apt update && sudo apt install -y \
  python3 python3-pip python3-venv redis-server zaproxy
# 2. Clone & setup backend
git clone https://github.com/Steven5233/vulnora.git && cd vulnora/backend
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 3. Start services (separate terminals)
sudo systemctl start redis-server
zap.sh -daemon -port 8090 -config api.disablekey=true
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
celery -A celery_app worker --loglevel=info
# 4. Start frontend
cd ../frontend && streamlit run app.py --server.port 8501
